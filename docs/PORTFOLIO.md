# Portfolio narrative

AccordFlow demonstrates a single coherent business journey rather than unrelated dashboard widgets: documentary evidence becomes deterministic findings, human review, independent approval and a reconstructable audit record.

| Discipline | Demonstrated work | Useful demonstration |
|---|---|---|
| Business analysis | Personas, acceptance criteria, SRS/BRD, workflow and RTM | Explain why a finding cannot simply disappear |
| QA/SQA | Risk-based strategy, rule boundaries, API/security/E2E, defects and evidence | Show 0.01-over-tolerance test and IDOR denial |
| Backend engineering | FastAPI services, SQLAlchemy transactions, migrations, provider interfaces | Trace an upload through hashing, versioning and validation |
| Security | Argon2id, sessions/rotation, permissions, object scope, audit integrity | Promote a maker to checker and show approval still blocked |
| Trade-finance operations | LC terms, documentary consistency, discrepancy handling, four-eyes review | Compare a late shipment against permitted latest shipment |
| Observability | Safe correlated errors, request counters, audit events, worker states | Correlate a rejected action with its request identifier |
| Frontend engineering | Typed React, accessible controls, responsive themes, integrated operations | Create a credit and approve using separate roles |
| Governance | Versioned rules, preserved overrides, operational configuration | Change a rule and explain why old validation becomes stale |

The strongest interview material is the boundary of each claim: the project shows application-level assurance, while explicitly identifying the regulated banking controls it does not yet provide.
